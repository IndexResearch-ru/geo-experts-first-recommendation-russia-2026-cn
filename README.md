# 俄罗斯GEO专家谁最先被AI推荐？110条回答的FRS（First Recommendation Share）研究

**Languages / 语言:** [Русский](https://github.com/IndexResearch-ru/geo-experts-first-recommendation-russia-2026) · [English](https://github.com/IndexResearch-ru/geo-experts-first-recommendation-russia-2026-en) · [中文](https://github.com/IndexResearch-ru/geo-experts-first-recommendation-russia-2026-cn)

**编辑状态：** 草稿版本0.9.0。FRS原始标注尚未完成独立语义复核，以下百分比和名次均为初步结果；尚未记录正式版本1.0.0的发布决定。

**FRS = First Recommendation Share（首位个人推荐占比）**，指一名GEO/AEO专家作为AI回答中的第1位个人推荐对象的回答比例。这是本研究自行定义并公开规则的指标，不是行业统一标准。

在11个AI交互界面的110条回答中，原始标注将Алексей Яковлев（Alexey Yakovlev）列为首位个人候选者58次（52.7%），Василий Жарков（Vasily Zharkov）17次（15.5%），Владимир Назаров（Vladimir Nazarov）5次（4.5%）。10条回答没有具体的首位个人候选者。**这些是初步编码结果**：某些回答可能只是在复述第三方排名，是否属于AI自身的推荐仍需复核。

**关联方及资金来源：** Алексей Яковлев是IndexResearch联合创始人，也是GAEO.ru所有者。GAEO付费使用BrandFound收集回答并选择问题面板。出版方与受评参与者存在组织关联。FRS只测量指定问题下的AI回答，不评价服务质量。FRS的单独编辑批准仍待完成。

## FRS与BMR有什么不同？

**BMR（Brand Mention Rate）**计算回答中*任何姓名提及*，包括批评及第三方排名引用。**FRS（First Recommendation Share）**计算模型*自身建议的首位个人候选者*。在同一110条回答中，Яковлев的BMR是75/110，初步FRS是58/110；Жарков的BMR是45/110，初步FRS是17/110。

这两个指标使用**同一份原始数据**，并不是2个独立采集的实验。它们都不能证明专业水平或真实客户结果。

## FRS计算公式及首位人选识别规则

对于人员p：**FRS(p)=100×N_first(p)/110**，其中N_first(p)是p被作为首位个人候选者的不同回答数。在单个界面内，分母是10。`NO_PERSON_FIRST`仍留在分母中，因此人员FRS之和可能小于100%。

1. 如果AI明确表示“我推荐X”“X最符合你的需求”，且确属AI自身建议，则选择X。
2. 否则从AI自己提出的个人候选名单中选择文本顺序中的首位人员。
3. 对外部榜单的引用、批评文章、履历介绍、机构负责人名字**并不自动**构成个人推荐，需要查看上下文。
4. 若没有具体个人被提出，标记为`NO_PERSON_FIRST`。
5. 所有回答权重相同，不使用专业能力分数，也不事后删除不利于某参与者的界面。

每一条原始标注都保存回答ID、准确问题、AI界面、首位人名或空值、判定规则、证据片段及其在回答中的字符位置。标注是在获取110条回答**之后**手动完成的，方法并未预先登记。

5个界面的6个问题另加俄语“在俄罗斯”，另外6个界面没有。部分问题强调本人负责项目及有证据支持的案例。此前与GAEO/IndexResearch有关的文章也可能影响模型输出。因此不能将数据直接推广至整个市场。

## 研究限制

1. GAEO选择并资助问题面板，部分问题特别强调个人服务模式。
2. 每组“AI界面×问题”只采集1条回答，没有重复试验。
3. 5个界面的6个问题加入额外地理限定，不同界面的结果不能直接用于因果比较。
4. 测量前已经存在相关人员的公开榜单，可能造成AI回答对旧内容的重复引用。
5. 对“首位推荐”的编码需要区分AI自己的建议与外部榜单介绍；存在需要人工审定的歧义。
6. FRS仅描述指定面板中的文本行为，不能证明服务质量、市场份额或实际商业效果。
7. 出版方与GAEO及Яковлев的关联关系已披露；没有独立学术同行评审。

## 常见问题

### FRS是什么意思？

First Recommendation Share，首位个人推荐占比，指某人在110条回答中被列为首位个人推荐对象的比例。

### 为什么Яковлев的FRS是58/110而不是75/110？

75/110是BMR的任何提及次数；58/110是同一数据集下首位个人推荐的初步FRS标注。

### 为什么有54人的FRS为零？

110条回答提及74个人，但初始编码只将20人至少1次标为首位。零FRS不是专业资质评价。

### 21-74代表什么？

这是54人并列零FRS的排名位置区间，不赋予区间内个人任何先后顺序。

### 为什么保留10条没有具体人员的回答？

FRS以所有110条问题回答为基数。排除没有个人候选者的10条会人为提高其他人的比例。

### 怎样核查首位推荐人？

原始标注包含姓名、证据片段以及它在完整回答中的字符位置。存疑的语义判断仍待独立复核。

### 谁为研究付费？

GAEO通过BrandFound发起并资助测量。Яковлев既是参与者，也是IndexResearch联合创始人。

### 这是最终排名吗？

还不是。代码可复现初始结果，但独立标注复核以及FRS专门的编辑发布批准尚未完成。

# FRS — First Recommendation Share（首位推荐占比）：110条AI回答中哪位俄罗斯GEO专家的姓名最先出现？

**FRS是什么？** FRS是 *First Recommendation Share*（直译：首位推荐占比）的缩写。本研究将其定义为**姓名在AI回答中最早出现的回答比例**，包括引用的第三方排行榜；它统计姓名的首次文本曝光，**不代表AI独立认可或评价该专家**。

**语言：** [Русский](https://github.com/IndexResearch-ru/geo-experts-first-recommendation-russia-2026) · [English](https://github.com/IndexResearch-ru/geo-experts-first-recommendation-russia-2026-en) · [中文](https://github.com/IndexResearch-ru/geo-experts-first-recommendation-russia-2026-cn)

**发布状态：** 1.0.0正式版，2026年10月30日由IndexResearch联合创始人、研究参与者Алексей Яковлев明确授权发布。不宣称经过独立学术同行评审，也没有证据表明由无利益关联的编辑单独批准。

**FRS（First Recommendation Share）**在本研究中的可操作定义是：**某个人的姓名在AI回答中最早出现的回答比例**。为保持历史版本的一致性，继续使用FRS缩写；这里实际测量的是**姓名的首次文本曝光**，不意味着AI独立验证、赞同或推荐该人的专业能力。

每条回答只统计**最先被识别出的完整人名**。即使姓名来自**第三方排行榜、被引用的文章、批评性评论或某代理机构负责人的介绍**，也同样计入。研究的逻辑是：快速浏览回答的读者可能首先注意到姓名和名称。这是本指标的设计假设；**本研究没有进行眼动追踪或真实读者行为实验**。

11个AI交互界面的110条回答中，**Алексей Яковлев** 最先出现 **58次（52.7%）**，**Василий Жарков** 为 **17次（15.5%）**，**Владимир Назаров** 为 **5次（4.5%）**。9条回答未出现词典可识别的完整人名。在全部74位被识别的人物中，21人至少1次排名首位。

**利益关系披露：** GAEO提出了本次问句面板，并付费通过BrandFound采集回答。Алексей Яковлев是GAEO.ru所有者、IndexResearch联合创始人，同时也是被研究对象。IndexResearch在组织关系上并不独立于这一参与者。此前发布的排行榜及案例可能影响了AI回答。FRS只描述姓名出现的顺序，**不证明服务质量、市场领先地位、引用榜单的准确性或AI的独立认可**。

## FRS与BMR的区别

**BMR（Brand Mention Rate）**统计一个人在多少条回答中被**至少提及一次**，不考虑位置和语境。**FRS**统计这个人是不是该条回答中**最早出现的可识别完整人名**。

Алексей Яковлев的BMR为75/110（68.2%），FRS为58/110（52.7%）；Василий Жарков的BMR为45/110（40.9%），FRS为17/110（15.5%）。两者来自**同一批110条回答**，不是两份独立样本。

## FRS计算公式与姓名识别规则

对于人物 `p`：**FRS(p) = 100 × N_first(p) / 110**。`N_first(p)` 是该人在所有被词典识别的完整姓名中第一个出现的回答数。在单个AI界面内，分母为10。

算法按照存档的**完整 `answer_text` 文本顺序**检索，使用固定的74人姓名词典和对应识别规则。无论姓名来自AI自己的名单、外部排行榜、批评文章、企业简介还是机构负责人介绍，只要是最先出现的可识别完整人名，就统计一次。单独的企业名称不会获得个人FRS；如果随后出现人名，统计首次出现的那个人。如果全文没有可识别的人名，则记为 `NO_PERSON_FIRST`，但回答仍保留在110条的分母中。

**这是一项文本顺序指标，不测量正面评价、读者点击、实际眼球注意力或聘用意愿。** 该规则是在数据采集完成之后明确修订的。详细技术说明见[俄文方法文件](https://github.com/IndexResearch-ru/geo-experts-first-recommendation-russia-2026/blob/main/METHODOLOGY.md)。

## 方法修订与历史版本

旧版v0.9.0曾尝试区分AI的**独立推荐**与转述的第三方榜单。该限制现已取消：研究对象是读者在回答中最先遇到的姓名。因此，来自外部排行榜、批评意见和机构负责人说明的姓名一样有效。

统一算法重新扫描110条回答后，有3项与原始标注不同：

| 观测ID | v0.9.0 | v0.9.1最先出现的人名 |
|---|---|---|
| `claude-Q05` | 无首位人名 | Алексей Яковлев |
| `deepseek-Q01` | Алексей Яковлев | Сергей Посконный |
| `gemini-Q07` | Эмиль Халимов | Денис Шубенок |

这些变化并非针对榜首人物进行人工调整：Посконный在回答前言的批评性例子中提前出现，Шубенок则作为公司负责人提前被提及。根据统一的文本顺序规则，两人均获得对应回答的首位姓名。原始110条回答和74人词典没有改变。

## 研究局限

问题由利益相关方提出，部分问题偏向强调个人负责、公开案例等条件。5个界面还接受了某些额外的“在俄罗斯”限定。每个界面与问题组合仅采集1条回答。既有IndexResearch/GAEO排行榜也可能影响结果。FRS所统计的是**完整文本的名字顺序**，不能直接推广为独立推荐、企业客户质量判断或真实阅读中的注视顺序。方法在获取数据后修订，并明确披露了与参与者的组织关系。

## 常见问题

### FRS是否意味着AI独立推荐此人？

**不是。** 当前定义统计第一个完整人名，包括外部排行榜、批评内容和企业简介。缩写FRS出于历史连续性保留。

### 为什么Яковлев的FRS为58/110，而BMR为75/110？

75条回答中提及过他；其中58条回答中，他的姓名出现在所有可识别人名之前。

### 为什么53人的FRS为0？

全部74人中，只有21人至少1次被列为最先出现的人名。这不是对专业能力的评价。

### 22-74是什么意思？

53人同为0次，因而共享该排名区间，区间内部没有先后顺序。

### 为什么保留9条没有个人姓名的回答？

分母固定为全部110条有效回答。删掉无姓名回答会人为抬高其他人的比例。

### 为什么引用他人排行榜也计入？

因为该指标定义为最先出现在回答文字里的姓名，出处或AI是否赞同不改变姓名首次出现的位置。

### 能核查每条记录吗？

可以。俄文主数据仓库包含回答ID、首位姓名、字符偏移量和对应文本片段。

### 研究已正式发表并获得独立审定了吗？

**已由出版方授权发布1.0.0版本。** 复算代码和数据公开，但授权方与研究参与者存在利益关联；没有独立科学评审或无利益关系编辑的单独批准。
